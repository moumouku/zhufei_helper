# 派蒙助手使用说明书

## 1. 软件简介

派蒙助手是一款 Windows 串口调试上位机，适用于嵌入式设备、开发板和串口模块的收发调试。

软件只负责原始字节的收发和显示，不解析设备协议。接收数据可以按文本或 HEX 显示，发送数据也可以选择文本或 HEX。

## 2. 启动软件

### 2.1 使用已打包版本

双击下面的文件：

```text
E:\projects_learning\zhufei_helps\dist\PaimonAssistant.exe
```

也可以在 PowerShell 中执行：

```powershell
& "E:\projects_learning\zhufei_helps\dist\PaimonAssistant.exe"
```

打包版本不需要目标电脑安装 Python。

### 2.2 使用源码版本

在项目根目录执行：

```powershell
.venv\Scripts\python.exe main.py
```

## 3. 主界面

主界面分为四个区域：

1. 串口参数区：端口、波特率、数据位、校验位、停止位和刷新按钮。
2. 模式控制区：接收模式、发送模式、编码、打开/关闭和清空按钮。
3. 接收显示区：显示设备收到的原始数据。
4. 发送区：输入并发送文本或 HEX 数据。

软件启动时会自动枚举当前可用串口。启动后软件以约 1 秒间隔持续监测串口变化，发现新端口会自动加入列表；点击“刷新”仍可以立即执行一次枚举。监测只更新列表和选择，不会自动打开端口。

## 4. 串口参数

### 4.1 端口

“端口”下拉框显示系统当前检测到的 COM 口，例如：

```text
COM3
COM4
```

如果列表为空，需要先连接设备，或者安装并创建虚拟串口。当前选择有效时，新插入端口不会改变选择；当前选择为空或已失效时，会自动选择本次枚举顺序中的第一个新端口。拔出未选中的端口会静默移除；拔出已选中但未连接的端口后，选择会留空，不会自动补选其他端口。

### 4.2 波特率

预置档位：

```text
9600
19200
38400
57600
115200
230400
460800
921600
```

波特率下拉框可以手动输入其他正整数。

### 4.3 高级参数

默认值为 `8 / N / 1`：

| 参数 | 可选值 | 默认值 |
| --- | --- | --- |
| 数据位 | 5、6、7、8 | 8 |
| 校验位 | N、E、O、M、S | N |
| 停止位 | 1、1.5、2 | 1 |

常见设备参数为 `115200 / 8 / N / 1`。

## 5. 打开和关闭串口

1. 选择有效 COM 口。
2. 设置波特率和高级参数。
3. 点击“打开”。
4. 打开成功后按钮显示“关闭”，串口配置控件会暂时禁用。
5. 再次点击“关闭”即可断开串口。

如果端口不存在、被其他程序占用或设备已经断开，软件会弹出错误提示，并恢复到可以重新选择串口的状态。打开连接期间端口列表仍会持续更新，端口下拉框和串口参数保持禁用，但“刷新”按钮仍可用。已连接端口连续两次约 1 秒轮询都不可见时，软件会自动关闭连接并提示“串口已拔出，连接已关闭”；端口在第二次轮询前恢复时不会误报。

## 6. 接收数据

### 6.1 文本模式

“接收”选择“文本”时，接收字节会按照“编码”选择解码。

支持两种编码：

- `UTF-8`
- `GBK`

编码必须和设备发送数据时使用的编码一致，否则中文可能显示为替换字符或乱码。

文本接收支持跨多个串口数据块的 UTF-8/GBK 字符，不会因为一次 read 被拆分而立即丢失完整字符。

### 6.2 HEX 模式

“接收”选择“HEX”时，每个字节显示为大写的两位十六进制，并使用空格分隔。

例如：

```text
设备字节：48 65 6C 6C 6F
显示内容：48 65 6C 6C 6F
```

HEX 模式适合检查协议帧、控制字节、零字节和非文本数据。

### 6.3 自动滚动

接收区追加新数据后会自动显示最新内容。切换文本/HEX 或编码时，软件会重新渲染已有原始历史；如果切换前位于底部，会继续保持底部可见。

如果需要查看旧数据，可以用鼠标滚轮向上滚动；新的接收数据到达时，显示区会回到最新位置。

### 6.4 清空接收区

点击“清空”会同时清除：

- 当前接收显示内容
- 已保存的原始接收历史
- 点击清空时尚未显示的待处理接收数据

清空后新到达的数据仍会正常显示。

## 7. 发送数据

### 7.1 发送文本

1. “发送”选择“文本”。
2. 选择正确的编码。
3. 在发送输入框中输入内容。
4. 点击“发送”，或输入完成后按回车。

例如，发送中文时：

- 设备使用 UTF-8：选择 `UTF-8`。
- 设备使用 GBK：选择 `GBK`。

### 7.2 发送 HEX

1. “发送”选择“HEX”。
2. 输入两位十六进制字节。
3. 点击“发送”。

空格和逗号都可以作为分隔符，也可以混合使用：

```text
48 65 6C 6C 6F
48,65,6C,6C,6F
48 65,6C 6C,6F
```

以上三种写法都会发送：

```text
Hello
```

以下输入会被拒绝并提示错误：

```text
GG 01
0x01
01 2
123
```

HEX 模式下不能使用 `0x` 前缀，每个字节必须正好是两位十六进制字符。

## 8. 虚拟串口联调

没有真实设备时，可以使用 com0com 创建一对虚拟串口，例如：

```text
COM3 <-> COM4
```

### 8.1 创建端口

安装 com0com 后，以管理员身份打开 com0com 的命令行工具，创建端口对：

```text
install PortName=COM3 PortName=COM4
```

不同 com0com 版本的命令行界面可能略有差异，以安装目录中的 `setupc.exe` 帮助为准。

### 8.2 使用派蒙助手连接 COM3

1. 启动派蒙助手。
2. 点击“刷新”。
3. 选择 `COM3`。
4. 设置 `115200 / 8 / N / 1`。
5. 点击“打开”。

### 8.3 使用 COM4 另一端测试

可以使用 pyserial 自带的终端工具连接 COM4：

```powershell
cd E:\projects_learning\zhufei_helps
.venv\Scripts\python.exe -m serial.tools.miniterm COM4 115200
```

从 COM4 输入文本，派蒙助手应收到对应数据。也可以从派蒙助手发送数据，观察 COM4 终端是否收到。

### 8.4 精确发送测试字节

下面的命令从 COM4 发送 UTF-8 字符串：

```powershell
cd E:\projects_learning\zhufei_helps
.venv\Scripts\python.exe -c "import serial; s=serial.Serial('COM4',115200); s.write('你好'.encode('utf-8')); s.close()"
```

派蒙助手在 UTF-8 文本模式下应显示：

```text
你好
```

HEX 模式下应显示：

```text
E4 BD A0 E5 A5 BD
```

### 8.5 检查异常处理

可以用以下方式检查错误提示：

- 用另一个程序先打开 COM3，再在派蒙助手中尝试打开 COM3。
- 启动两个派蒙助手实例，让它们竞争同一个 COM 口。
- 设备或虚拟串口断开后继续发送数据。
- 保持派蒙助手连接 COM3，使 COM3 短暂消失后在一次轮询内恢复，确认不会误关闭；连续两次轮询仍消失时，确认自动关闭并提示“串口已拔出，连接已关闭”。
- 拔除未选中的端口，确认静默移除；拔除已选中但未连接的端口，确认选择留空且不会自动打开其他端口。
- 在 HEX 发送模式输入非法字符。

预期结果是出现明确提示，程序不崩溃，并且可以重新选择端口后再次打开。

## 10. 已知限制

- 软件只展示原始数据，不解析具体协议。
- 接收历史保存在内存中，长时间高流量运行会增加内存占用；可以定期点击“清空”。
- 串口配置目前不会自动保存，下次启动需要重新选择。
- com0com 是外部测试工具，不是派蒙助手的运行时依赖。
