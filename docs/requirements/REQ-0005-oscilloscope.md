# REQ-0005 派蒙助手：独立示波器页面与十进制数值波形协议

| 属性 | 内容 |
|---|---|
| 需求编号 | REQ-0005 |
| 需求名称 | 派蒙助手：独立示波器页面与十进制数值波形协议 |
| 需求状态 | 已确认 |
| 创建日期 | 2026-09-23 |
| 更新日期 | 2026-09-27 |
| 关联需求 | REQ-0001、REQ-0002、REQ-0003、REQ-0004 |

## 1. 目标

在派蒙助手中新增独立的示波器页面。页面通过自己的串口接收会话和协议解析器读取最多 8 个十进制数值通道，实时绘制波形，并显示示波器收到的原始内容；相对时间显示在波形图 X 轴和悬停读值中。

示波器与既有数据页共用一个物理串口及其参数设置，但同一时刻只能有一个页面接收。两个页面的接收消费者、解析状态、数据显示和历史相互独立。

## 2. 范围与既有需求关系

### 2.1 包含范围

1. 新增“数据”和“波形”两个可切换页面。
2. 为数据页和示波器页分别提供独立的接收开始/停止控制及接收历史。
3. 在示波器页按严格 `\r\n` 分帧并解析 1～8 个有符号十进制数值。
4. 同步显示波形、示波器页收到的原始内容和通道控制；相对时间显示在图表坐标和悬停读值中，协议失败与连接边界显示在接收正文之外的非模态提示中。
5. 保存最近 180 秒内的全部原始波形采样点，并为图表提供缩放、平移、历史查看、自动缩放及悬停取值交互。
6. 将示波器页完整数据帧写入现有 `RX` 日期日志。

### 2.2 不包含范围

1. 不改变数据页既有文本/HEX 显示、UTF-8/GBK、时间戳、日志、跟随最新、清空及端口热插拔行为。
2. 不在数据页“原始字节”模式下解析数据或生成波形。
3. 不把 MCU 采样时钟加入串口协议；本需求的波形时间是主机识别帧完成时的接收时间，不声称等于 MCU 实际采样时间。
4. 不改变发送数据字节、发送端结束符或回显行为。
5. 不要求增加外部运行时依赖；图表使用当前 PySide6 环境提供的 QtCharts。

### 2.3 与 REQ-0001～REQ-0004 的关系

1. REQ-0001 的串口参数、发送和基本连接错误处理保持不变。
2. REQ-0002 的端口列表监测、选择和热插拔关闭规则保持不变。
3. 数据页继续遵循 REQ-0003 的严格分帧事件、时间戳、日志及故障隔离规则。
4. 数据页继续遵循 REQ-0004 的解析模式选择；选择“原始字节”时不解析载荷。
5. 本需求新增独立示波器接收消费者。示波器页无论数据页选择何种解析模式，都使用本需求规定的十进制数值协议解析器。
6. 示波器页日志仍使用 REQ-0003 的日期文件、绝对本地时间戳、原始帧 HEX 格式、保留清理和日志故障熔断规则；示波器接收正文只显示原始载荷内容，不显示 `payload=""`、逐帧相对时间或解析成功标记。

## 3. 术语

**数据页**：现有串口接收页面，支持按 `\r\n` 分帧或原始字节显示。

**示波器页**：新增波形页面，独立按 `\r\n` 分帧、解析十进制数值协议并显示波形。

**接收消费者**：当前获得物理串口输入数据并负责维护对应队列、分帧状态和页面历史的唯一页面。

**采集会话**：示波器首次开始接收后建立的时间原点、采样历史和通道推断状态。停止再开始不创建新会话；清空波形/新建采集会话时才重置。

**采样点**：一条合法示波器帧中的通道数值集合及其单调时钟相对时间。

**帧完成时间**：主机接收线程识别到数据帧 `0D 0A` 边界时记录的时间，不代表设备端采样时刻。

## 4. 页面、连接与接收互斥

### 4.1 页面与控件

1. 主窗口提供“数据”和“波形”两个页面，启动默认进入数据页。
2. 两个页面共用串口端口、波特率、数据位、校验位和停止位设置，以及现有发送能力。
3. 数据页保留现有接收工具栏和接收显示区；波形页拥有自己的开始/停止接收控制、清空波形控制、数据显示区、波形图和通道栏。
4. 数据页沿用现有串口打开/关闭操作语义；波形页使用自己的示波器开始/停止接收操作。
5. 启动软件时两个页面均未开始接收。

### 4.2 接收互斥与页面切换

1. 任意时刻最多有一个页面可以接收串口数据；不得向两个页面广播同一批输入数据。
2. 页面开始接收后，该页面成为唯一接收消费者；在其停止接收并关闭串口前，页面切换操作必须被禁止。
3. 停止接收会关闭当前串口连接。停止后页面切换重新允许；切换到另一个页面时，该页面默认处于停止接收状态，必须由用户主动开始。
4. 页面切换不会自动打开串口、自动开始接收、停止另一页面的活动采集或清除任一页面历史。
5. 活动接收期间串口异常、端口拔出或程序关闭，必须关闭失效连接并按当前活动页面的连接错误路径处理；另一页面不得收到失效会话遗留的数据。
6. 发送仅作用于当前已打开的物理串口，不将发送内容注入任何页面的接收历史或波形。

### 4.3 接收会话隔离与停止边界

1. 串口输入只交付给当前活动页面的队列和接收历史。
2. 数据页和示波器页分别维护接收事件/原始字节历史、未完成帧、诊断和清空状态；两者互不共享或回放彼此历史。
3. 停止活动页面时，必须在接收会话同步边界关闭连接，丢弃该会话中尚未消费的队列数据及未完成帧。
4. 重新开始接收时创建新的连接接收会话，并清除串口驱动中可能残留的待读输入；只能处理重新开始后新进入接收链路的数据。停止期间设备继续发送不得使软件阻塞设备发送，也不得在重新打开后作为旧数据补交。
5. 页面清空只重置当前页面历史和解析状态，不改变另一页面的队列、历史、日志或接收模式。

## 5. 示波器协议

### 5.1 语法

一帧载荷严格由 1～8 个有符号十进制数值构成，数值之间使用 ASCII 半角逗号 `,` 分隔，帧结束符为实际字节 `0D 0A`（`\r\n`）。等价语法为：

```text
[+-]?(?:[0-9]+(?:\.[0-9]*)?|\.[0-9]+)(,[+-]?(?:[0-9]+(?:\.[0-9]*)?|\.[0-9]+)){0,7}\r\n
```

示例：

```text
12\r\n
12,34\r\n
0.96,328.00\r\n
-0.13,330.00\r\n
-10,+20.5,0030\r\n
```

每个值必须落在原有有符号 32 位数值范围内：

```text
-2147483648 .. 2147483647
```

先按十进制值精确校验范围，再转为双精度浮点（binary64）保存和绘图；旧 int32 整数仍可精确表示，小数允许 binary64 舍入，接收正文及 RX 日志保留原始拼写和字节。

### 5.2 分帧规则

1. 示波器页使用与 REQ-0003 相同的严格 `0D 0A` 边界规则，包括跨串口读取块、多帧和单独 `\r` / `\n` 的处理。
2. 示波器页自己的分帧器不得读取或修改数据页分帧器状态；数据页解析模式不影响示波器页分帧。
3. 未完成帧不进入数据显示、波形、时间戳或日志；停止、清空或会话切换时丢弃未完成帧。
4. 沿用 REQ-0003 的未完成载荷 `1 MiB` 上限及超长帧恢复规则，避免无结束符输入导致无界累积。超长帧丢弃且通过非模态示波器诊断提示，不生成事件或日志。

### 5.3 非法帧

1. 完整但不符合 §5.1 的帧仍作为示波器接收数据保存并显示原始载荷，在页面内、接收正文之外的协议状态区域标记“解析失败”。
2. 非法帧不得生成任何波形采样点，也不得改变通道数量。
3. 非法帧的完整原始帧仍写入现有 `RX` 日期日志。
4. 协议错误使用页面内非模态状态/诊断显示，不因每个错误帧弹出模态对话框；串口打开、读写失败沿用现有连接错误处理。
5. 空帧 `\r\n` 是完整但非法的示波器帧，按上述方式显示、标记并记录日志。

## 6. 示波器时间与数据区

### 6.1 时间来源

1. 每次创建新的示波器采集会话时建立高分辨率单调时钟原点 `T+0`。
2. 每个完整帧在接收线程识别其 `\r\n` 边界时记录单调时钟和主机本地墙上时钟。
3. 波形 X 坐标和悬停读值使用：`frame_monotonic_time - acquisition_origin`，单位为秒；示例格式为 `T+012.345 s`。相对时间不写入接收正文。
4. 单调时间用于排序、绘图和相对时间，不因系统时钟校准或时区变化而跳变。
5. 现有 `RX` 日志继续使用帧完成时的主机本地绝对时间，格式和日期分文件规则遵循 REQ-0003。
6. 本协议没有 MCU 采样时间字段；不得把主机收到完整帧的时间标称为 MCU 实际采样时刻。

### 6.2 开始、停止和恢复

1. 首次成功开始示波器采集时建立采集时间原点。
2. 停止接收关闭串口并丢弃待处理数据，但保留波形、通道和数据显示历史。
3. 重新开始示波器接收时继续原采集会话及原时间原点。停止期间经过的时间计入恢复后的相对时间，期间不生成采样点。
4. 如果停止后端口或串口参数与前一次连接不同，恢复时在接收正文之外显示新的连接参数边界提示；已有波形和时间原点保持不变。
5. 如果停止后端口和串口参数未变化，恢复时仍建立新的串口读取会话并丢弃残留输入；不得拼接停止前的半帧。
6. 清空波形/新建采集会话会将时间原点重置为清空时刻；若此时仍在接收，接收继续，清空后的下一条完整帧使用新原点计算时间。
7. “暂停接收”不是冻结串口队列；不接收、不缓存、不回放暂停期间的设备输出。

### 6.3 示波器数据显示区

1. 示波器页有独立数据显示区，与数据页的接收文本完全分离。
2. 每个完整示波器帧在接收正文中只显示原始载荷内容；合法帧产生数值采样，非法帧在正文外显示解析失败提示。相对时间只显示在图表坐标和悬停读值中。
3. 完整帧按接收顺序逐行显示原始载荷；可打印 ASCII 原样显示，不可打印字节转义显示，不添加引号、时间或解析状态。记录和日志中保存的原始帧字节不得改变。
4. 数据区最多保留最近 180 秒内完成的完整帧记录，包括合法帧和非法帧；按最新完整帧的相对时间淘汰更早记录。
5. 停止接收期间不因电脑时间流逝而淘汰数据显示区或波形历史；恢复后随新帧到达再按 180 秒窗口淘汰。
6. 数据区默认跟随最新帧。用户查看较早记录时，后续数据继续接收但不强制移动其阅读位置；提供返回最新位置的操作。

## 7. 通道与波形数据

### 7.1 动态通道

1. 每个采集会话最多建立 8 个通道，按字段顺序命名为 `CH1` 至 `CH8`。
2. 第一条合法帧建立该帧字段数对应的通道；后续帧字段数更大时动态增加通道。
3. 通道数量按当前会话中见过的最大合法字段数确定；短帧、非法帧和旧样本淘汰不得使通道数量减少。
4. 对缺少后续字段的合法短帧，在对应通道和该帧时间处形成数据缺口；不得沿用或重复上一个值。
5. 新出现的通道默认显示。右侧通道栏为每个已发现通道提供独立开关和最新有效值；关闭通道只隐藏曲线，不停止该通道采集。
6. 清空波形/新建采集会话后清除所有通道及开关状态，后续合法帧重新推断通道数。
7. 通道名称和值均可见；通道不得仅依颜色区分。

### 7.2 原始采样保留与滚动窗口

1. 每条合法帧在同一个相对时间上产生一组采样；只为该帧实际提供的字段记录值。
2. 保留最近 180 秒范围内的全部原始采样值和时间，不按固定点数上限或采样频率降采样删除原始点。
3. 滚动淘汰以最新合法采样点的相对时间为基准，而非电脑当前时钟。
4. 停止接收后没有新采样时，不仅因为等待时间变长而删除历史；恢复并产生新采样后，再按新的采样时间滚动淘汰超出 180 秒的旧数据。
5. 保留数据使用紧凑存储；不得把图表绘制对象作为原始数据的唯一存储形式。
6. 如内存分配失败或继续保留/绘制数据已无法安全进行，必须停止示波器接收、保留已有数据并显示非模态错误；不得静默丢弃仍在 180 秒窗口内的原始采样点。

### 7.3 图表绘制

1. 图表以接收相对时间为 X 轴、十进制数值采样为 Y 轴。
2. 所有显示通道共用同一 Y 轴，方便对比同一时刻的数值。
3. 图表可以按当前视口像素尺寸及缩放级别对绘制输入进行降采样，但降采样不得修改或删除 §7.2 保留的原始点。
4. 降采样须保留时间桶内的局部最小值和最大值，避免高频信号尖峰因绘制简化而消失；放大或改变视口后按新的视图重新生成绘制数据。
5. 数据缺口必须显示为曲线断开，不得跨缺口连线或使用旧值填补。
6. 曲线颜色采用主题中可区分的多色方案，并通过通道名称/状态同时表达身份；图表和通道栏延续「派蒙·石墨」主题。

## 8. 波形视图交互与坐标范围

1. 支持对 X 轴和 Y 轴分别缩放；提供可见的横轴/纵轴缩放操作，不依赖鼠标滚轮作为唯一途径。
2. 默认鼠标滚轮缩放 X 轴；按住 `Ctrl` 滚轮缩放 Y 轴。横纵轴缩放应以指针附近的图表坐标为中心。
3. 在图表中按住鼠标左键可平移当前视图；默认同时移动 X/Y 轴，按住 `Shift` 只移动 X 轴，按住 `Ctrl` 只移动 Y 轴。
4. 鼠标靠近曲线数据时显示最近原始采样点的相对时间及该帧实际存在的通道和值；缺失通道不显示虚构值。鼠标没有靠近有效采样点时不显示误导性读数。
5. 提供“自动缩放”操作，一次性将 X 轴适配当前保留数据时间范围，并根据当前可见 X 范围内已打开通道的有效原始值范围设置 Y 轴；常值数据仍须有可见范围。
6. 自动缩放和回到最新是不同操作：自动缩放调整坐标范围；回到最新调整时间视口到最新数据并恢复实时跟随。
7. 用户手动缩放或平移后，新数据继续被采集，但不得把视口强制改回自动缩放或最新位置；提供明确的“回到最新”操作恢复跟随。
8. 当实时接收期间用户查看历史，接收和缓冲继续；若当前视口左侧历史因 180 秒淘汰而越界，视口夹紧到仍保留的数据范围，并以非模态状态提示历史正在滚动淘汰。
9. 当无有效数据时，轴显示合法默认范围；无通道开启时不绘制通道曲线，仍允许检查时间视口及重新选择通道。

### 8.1 轴边界

1. Y 轴硬范围沿用 int32 的数值上下界，不得超出 `-2147483648` 至 `2147483647`；正常默认视图不应直接固定显示整个 int32 范围而使常见小幅信号不可见。
2. X 轴范围不得延伸到当前保留数据时间窗之外；可回看范围最多为当前最新采样点向前 180 秒内仍保留的数据。
3. 手动缩放和平移不得产生反向或零宽坐标范围；在极限值和常值数据附近操作也必须保持有效坐标范围。

## 9. 清空与新建采集

1. 示波器“清空波形/新建采集”同时清除：
   - 示波器页波形原始采样历史与绘制数据；
   - 示波器页完整帧显示历史及对应的帧时间元数据；
   - 通道推断、通道开关和最新值；
   - 协议解析错误和接收诊断；
   - 当前图表缩放、平移和阅读位置；
   - 示波器当前输入队列中的待处理数据和分帧器未完成尾部。
2. 清空操作是串口接收会话内可线性化的边界；清空前已进入队列但尚未处理的数据不得在清空后复现。
3. 接收处于活动状态时点击清空，不关闭串口、不停止接收；清空时重置示波器时间原点，之后新收到的完整帧按新时间原点处理。
4. 示波器停止接收时清空仍安全；下一次开始后以新时间原点创建新的采集会话。
5. 清空不删除或修改已写入 RX 日志的记录，不影响数据页任何状态。

## 10. RX 日志与故障隔离

1. 示波器页每个完整 `\r\n` 数据帧都写入 REQ-0003 规定的 RX 日期日志，包括合法协议帧和完整非法帧。
2. 日志记录完整原始帧 HEX，包括结束符 `0D 0A`，时间为帧完成时的主机本地墙上时钟；不使用示波器相对时间替换日志时间。
3. 不完整帧和超过 1 MiB 后丢弃的帧不生成事件、不显示为完整帧、不写 RX 日志。
4. 日志仍使用 REQ-0003 的日期命名、格式、清理、同步刷新及首次失败熔断规则。
5. 日志失败不能停止示波器串口读取、分帧、协议解析、采样缓冲或波形显示；显示 REQ-0003 固定日志错误提示。
6. “数据”和“波形”共享现有日志服务和目录入口；日志是应用持久记录，不属于任一页面的内存历史，清空页面不得删除日志。

## 11. 串口参数变化与连接边界

1. 示波器停止后用户可以更改端口或任一串口参数，再次开始时使用当前设置。
2. 参数或端口变化不自动清除已有波形、通道或示波器数据显示历史，不创建新的时间原点。
3. 参数/端口与前次活动连接不同的情况下，恢复时在会话内记录连接边界时间及新参数，并在接收正文外显示连接边界及新参数提示；提示不显示相对时间，也不作为接收帧插入正文。
4. 清空或新建采集是显式重置数据集的操作；不得因停止、页面切换、参数更改或重连而静默清空历史。

## 12. 诊断与错误处理

1. 非法协议帧、超长未完成帧和资源不足等示波器问题以页面内非模态诊断显示，不连续弹窗。
2. 非法帧、资源错误与连接边界提示均位于接收正文之外，不遮盖或混入原始载荷；相对时间仅在图表和悬停读值中显示。
3. 串口打开、读取、写入、关闭、热拔插错误沿用项目现有错误处理；失效连接必须关闭，主窗口恢复可重新打开状态。
4. 页面切换锁定状态必须与物理串口连接及活动接收消费者一致；异常路径也必须解除锁定，不能留下无法切页的假接收状态。

## 13. 自动化测试与验收

### 13.1 协议与采集

1. 测试覆盖 1、2、8 通道合法帧、整数和小数、正负号、前导零、int32 数值边界及跨读取块 `\r\n`。
2. 测试覆盖空帧、空字段、尾逗号、空格、TAB、指数、`NaN`/`Inf`、非 ASCII 数字、非法字符、超过 8 通道、int32 数值溢出、单独 CR/LF 和超长帧。
3. 每个合法完整帧按顺序产生正确的单调相对时间、绝对日志时间、原始帧和通道值；非法帧只进入示波器数据显示和 RX 日志，不生成波形点。
4. 以注入单调时钟和墙上时间源测试采集时间原点、暂停间隔、继续采集、参数变化边界和清空重置；不依赖真实睡眠得到精确时序。
5. 验证数据页原始字节/分帧行为与示波器模式完全隔离，且任一时刻两个页面不能同时消费输入。

### 13.2 页面与会话

1. 启动默认进入数据页，两个页面均停止接收。
2. 只允许当前页面在串口打开时接收；接收期间不可切换，停止关闭串口并解除页面切换锁定。
3. 切换页面后新页面保持停止状态；必须由用户主动开始，且另一个页面的历史不会出现或被清除。
4. 停止、重新开始、端口参数变化、页面切换、清空以及拔出/读写错误均不泄漏旧队列内容或未完成帧。
5. 示波器恢复接收时清除驱动待读输入；停止期间发送的数据不会在恢复后作为旧数据被接收。
6. 活动接收期间清空是线性化的：清空前待处理帧不复现，串口保持打开，新帧以重置后的时间原点进入历史。

### 13.3 通道、保留和绘图

1. 通道数依据本次采集会话见过的最大合法字段数增加；短帧产生缺口，不沿用旧值；非法帧和时间淘汰不改变通道数。
2. 清空/新建采集后通道推断、通道开关、样本、显示历史和缩放范围正确重置。
3. 测试证明 180 秒窗口保存范围内全部原始点；按最新采样时间淘汰旧点；停止期间不会单纯因时钟前进淘汰历史。
4. 测试图表绘制降采样不修改原始缓冲，最小/最大尖峰可见，数据缺口不被连线。
5. 测试自动缩放只按可见时间和开启通道计算，X/Y 独立缩放、平移和 int32 边界保持有效。
6. 测试悬停显示真实最近原始点的相对时间和值，缺失通道不显示伪值；查看历史期间新数据到达不移动视口。
7. 使用 Qt offscreen 和可注入时钟测试页面、通道栏、诊断与图表状态；必要的鼠标交互可在支持 QtCharts 的 Windows 环境补充原生验收。

### 13.4 故障与交付

1. RX 日志分别验证合法帧、非法完整帧、未完成帧和超长帧的日志行为。
2. 验证日志熔断不影响示波器接收和绘图；内存/绘图资源失败停止示波器接收并保留已采集历史。
3. 全量既有测试继续通过，尤其是 REQ-0001 至 REQ-0004 的数据页行为、日志隔离、串口控制器会话及入口打包测试。
4. 实施完成后更新 README、`docs/user-manual.md`、`CHANGELOG.md` 和程序版本信息；同步补充新功能自动化测试。发布 EXE 与 Git 操作按项目发布流程另行执行，不属于本 REQ 文档落盘操作。

## 14. 已确认的决定记录

1. 两个页面共用一个物理串口，但接收消费者互斥；接收时禁止切页，停止关闭串口后才允许切页；切入页面后必须手动开始。
2. 页面接收历史、协议解析、数据显示、时间戳和清空状态完全隔离；数据页原始字节模式不解析示波器协议。
3. 示波器严格解析 1～8 个有符号十进制数值，兼容整数并支持小数，数值范围仍为 `-2147483648..2147483647`；以半角逗号分隔并以实际 `0D 0A` 结束，不允许空格、指数或其他格式外内容。
4. 示波器所有完整帧均保留在其独立历史并写入现有 RX 日志；接收正文只显示原始载荷，非法完整帧在正文外提示解析失败且不产生采样点。
5. 示波器时间以本次采集的高精度单调时钟原点计算，仅显示在图表 X 轴和悬停读值中；接收时间不代表 MCU 采样时间。RX 日志保留主机本地绝对时间。
6. 停止再开始继续同一采集会话和时间轴，停止期间不接收或缓冲；清空波形/新建采集才重置时间、样本和通道推断。
7. 当前会话按最大字段数动态增加通道；短帧缺失通道形成缺口；通道不因短帧或历史淘汰减少。
8. 保留最近 180 秒全部原始点，图表可视图降采样但不能改写原始点；资源不足时停止接收并保留已采数据。
9. 波形支持 X/Y 独立缩放、自动缩放、回到最新、鼠标平移和悬停读值；全部通道共用 Y 轴，受 int32 硬边界约束。
10. 示波器帧数据显示区同样保留最近 180 秒；帧记录按最新完整帧时间淘汰，采样按最新合法采样时间淘汰，停止期间不因墙上时间流逝删除。
11. 清空操作只作用于当前页面。示波器活动接收期间可清空，并在接收会话锁内清理队列和分帧尾部、重置时间原点，同时继续接收。
12. 停止后改变串口参数或端口不清除历史；重新接收时记录连接边界及新参数，并在接收正文外提示。
