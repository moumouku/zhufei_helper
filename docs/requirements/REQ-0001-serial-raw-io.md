## 1. 目标

实现一个名为“派蒙助手”的 Windows 桌面串口调试工具，用于配置串口、接收并显示原始字节，以及手动发送文本或 HEX 数据。

## 2. 功能需求

1. 软件启动时自动枚举可用 COM 口，并支持手动刷新端口列表。
2. 串口参数支持波特率、数据位、校验位和停止位配置，默认值为 `115200 / 8 / N / 1`。
3. 波特率预置 `9600`、`19200`、`38400`、`57600`、`115200`、`230400`、`460800`、`921600`，同时允许输入其他正整数。
4. 支持打开和关闭串口；打开后锁定串口配置，关闭后恢复配置能力。
5. 接收区实时显示原始数据，支持文本和 HEX 两种显示模式。
6. 文本模式支持 UTF-8 和 GBK，默认 UTF-8；跨读取块的多字节字符必须正确处理。
7. HEX 模式按大写两位十六进制字节显示，并以空格分隔。
8. 切换接收模式或文本编码时，基于已接收的原始字节重新显示历史内容。
9. 接收区支持自动滚动和清空；清空时同时清除已显示历史和尚未处理的待显示数据。
10. 发送区支持文本和 HEX 两种模式，文本按当前编码发送。
11. HEX 输入允许使用空格或逗号分隔，每个字节必须是两位十六进制字符；非法输入必须提示且不得发送。
12. 支持点击发送按钮或在输入框按回车发送数据。
13. 串口不存在、被占用、意外断开或读写失败时，软件必须提示错误、关闭失效连接并恢复到可重新打开的状态。

## 3. 技术约束

| 层级 | 方案 |
|---|---|
| 运行平台 | Windows 10 / 11 |
| Python | Python 3.10 / 3.11 |
| GUI | PySide6 6.6+ |
| 串口通信 | pyserial 3.5+ |
| 打包 | PyInstaller 6.x |
| 应用名称 | 派蒙助手 |
| 可执行文件 | `PaimonAssistant.exe` |

串口读取在独立线程执行，通过线程安全队列传递原始字节；Qt 主线程使用定时器批量刷新界面，避免串口读取阻塞 UI。每次连接使用独立的停止信号和接收队列，旧连接不得向新连接注入数据。

## 4. 实施与交付约束

1. 开发采用 TDD：先编写能够准确失败的测试，再实现最小代码使其通过，最后重构并运行完整测试。
2. 需要委派时，subagent 使用 `deepseek-v4-flash`；长任务每 5 分钟检查一次运行状态。
3. 自动化测试使用 fake serial 和 Qt offscreen 环境，不依赖真实串口或显示器。
4. 交付源码、无 Python 环境可运行的单文件 `dist/PaimonAssistant.exe`，以及中文使用说明书。
5. 无真实串口时，使用 com0com 创建 `COM3 <-> COM4` 虚拟串口对进行端到端手工验收。

## 5. 验收标准

1. 软件能够枚举、刷新、配置、打开和关闭串口；默认参数为 `115200 / 8 / N / 1`。
2. UTF-8、GBK 和任意原始字节能够分别以文本或 HEX 正确显示，模式切换不丢失已接收数据。
3. 文本和合法 HEX 能发送正确字节，非法 HEX 输入会被拒绝并显示明确提示。
4. 自动滚动与清空行为正确，高数据量到达时界面保持可响应。
5. 端口占用、连接断开及读写失败不会导致程序崩溃，处理后可以重新连接。
6. 在 115200 波特率持续收发场景下，读取线程能够停止，旧会话数据不会进入新会话。
7. 源码入口可以运行；`PaimonAssistant.exe` 能在无 Python 环境的 Windows 10/11 上启动。
8. com0com 的 `COM3 <-> COM4` 双向收发手工测试通过。
