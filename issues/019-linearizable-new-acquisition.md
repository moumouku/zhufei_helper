# 019 - 线性化清空与新建采集

## Type

AFK

## Parent PRD

`docs/requirements/REQ-0005-oscilloscope.md`（§4.3.5、§6.2.6、§7.1.6、§9、§10.6、§13.2.4、§13.2.6、§13.3.2）

## What to build

把“清空波形/新建采集”实现为波形接收会话内单一线性化边界：原子隔开清空前后输入，同时重置波形原始采样、帧数据显示、通道推断、通道开关及最新值、诊断、绘图缓存、坐标视图、悬停和阅读位置。清空前已经进入旧队列但尚未处理的数据和分帧尾部不得在清空后复现。

活动接收期间清空不关闭串口，边界后继续接收并以新采集原点计时；停止状态清空则令下一次成功开始建立新原点。该操作不能影响数据页状态或任何已写 RX 日志。

## Acceptance criteria

- [x] 单次操作清除波形原始采样、绘图 series/缓存、完整帧历史和相对时间显示
- [x] 同次操作清除 CH1～CH8 推断、开关和最新值，后续合法帧从零重新推断
- [x] 同次操作清除协议错误、超长/资源诊断、历史淘汰提示、悬停提示和数据显示阅读锚点
- [x] 同次操作将自动缩放、手动缩放/平移和实时跟随状态恢复为无数据默认视图
- [x] 会话锁内的代次/队列切换是唯一清空线性化点；清空前已入队未消费事件、旧 reader 延迟发布及未完成尾部均不能越过边界
- [x] 活动接收时清空不关闭串口、不释放当前页面接收所有权；清空后的下一条完整帧正常进入新历史
- [x] 活动清空时在同一线性化边界重置采集单调原点；后续帧相对时间基于新原点且非负
- [x] 停止状态清空安全且不打开串口；下一次成功开始为新采集建立原点
- [x] 波形清空不修改数据页事件历史、原始字节历史、解析模式、队列或诊断
- [x] 清空不删除、截断或改写任何既有 RX 日志；清空后的新完整帧仍按正常规则写日志
- [x] 并发 fake reader 与可注入时钟测试覆盖清空前尾部、排队帧、边界中到达数据和清空后新帧
