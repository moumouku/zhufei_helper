# 013 - 完整十进制数值协议、非法帧与超长帧诊断

## Type

AFK

## Parent PRD

`docs/requirements/REQ-0005-oscilloscope.md`（§2.3、§5、§6.3、§10、§12、§13.1）

## What to build

在单通道闭环上完成示波器独立协议路径：严格以 `0D 0A` 分帧，将载荷解析为 1～8 个以 ASCII 半角逗号分隔的有符号十进制数值，兼容旧整数写法并支持小数。所有完整帧均进入波形页接收正文并按原始字节写入 RX 日志；合法帧产生采样，非法完整帧保留原始载荷并在正文外标记“解析失败”，但不产生采样、不改变通道数。超长未完成帧按既有 1 MiB 边界丢弃并通过波形页非模态诊断提示。

波形分帧器、解析状态和诊断必须与数据页严格隔离；数据页选择“原始字节”不得影响波形页协议，波形输入也不得进入数据页任一接收通道。

## Acceptance criteria

- [x] 接受 1、2、8 通道帧，以及负号、可选正号、前导零、整数、小数和 int32 数值边界
- [x] 只接受 ASCII 数字及十进制数值语法 `[+-]?(?:[0-9]+(?:\.[0-9]*)?|\.[0-9]+)(,[+-]?(?:[0-9]+(?:\.[0-9]*)?|\.[0-9]+)){0,7}`；解析结果落在有符号 32 位数值范围内
- [x] 跨读取块的 `\r\n`、一次读取中的多帧、单独 CR、单独 LF 和 `\r\r\n` 均遵循严格连续 `0D 0A` 边界
- [x] 空帧、空字段、尾逗号、空格、TAB、指数、`NaN`/`Inf`、非 ASCII 数字、非法字符、超过 8 通道及 int32 数值溢出均显示原始载荷并在正文外提示“解析失败”
- [x] 每个合法完整帧只产生一个同时间的采样集合；每个非法完整帧不产生任何采样且不改变通道数量
- [x] 合法与非法完整帧均按帧完成墙上时间写入 RX 日志，日志使用完整原始帧 HEX
- [x] 未完成帧不显示、不采样、不写日志；停止、清空或消费者会话切换时独立丢弃波形分帧尾部
- [x] 载荷恰好 1 MiB 仍可完成；第一个超限载荷字节触发本段一次非模态诊断，并丢弃到下一个 `0D 0A` 后恢复
- [x] 超长帧不生成完整帧记录、采样或 RX 日志
- [x] 数据页分帧器、原始字节模式、历史和诊断不受波形协议状态影响；数据页原始字节绝不被波形解析
- [x] 纯单元测试覆盖完整语法和边界矩阵，控制器/Qt offscreen 测试覆盖显示、日志、诊断与页面隔离
