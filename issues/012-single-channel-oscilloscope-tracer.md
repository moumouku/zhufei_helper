# 012 - 单通道示波器首帧端到端贯通

## Type

AFK

## Parent PRD

`docs/requirements/REQ-0005-oscilloscope.md`（§1、§4、§5、§6.1、§10、§13.1-13.2）

## What to build

交付一条可运行、可演示的单通道示波器最小闭环：主窗口提供“数据”和“波形”两个页面，波形页能以唯一接收消费者身份开始接收，在 reader 识别完整 `0D 0A` 帧的同一时点记录单调时间与本地墙上时间，将简单单通道整数帧显示为相对时间数据记录和 CH1 曲线，并把同一原始帧按既有格式写入 RX 日志。停止波形接收必须关闭串口并重新允许切页。

本切片只将规范中的简单单通道整数（例如 `12`）作为合法采样贯通；其他完整载荷在本切片中必须安全地作为解析失败处理，不得误生成采样。完整 1～8 通道语法和错误矩阵由后续切片扩展。

## Acceptance criteria

- [x] 主窗口启动默认显示“数据”页，并可切换到独立“波形”页；两个页面启动时均未接收
- [x] 两页共用当前端口和串口参数设置及发送能力，但波形页拥有独立的开始/停止、数据显示区、图表、通道区和诊断区
- [x] 数据页开始接收或波形页开始接收后，当前页面成为唯一接收消费者；活动接收期间页面切换不可用
- [x] 波形页成功开始后接收 `31 32 0D 0A`（即 `12\r\n`），产生且只产生一个 CH1 原始采样，并在图表中出现一个对应数据点
- [x] 帧边界识别时关联同一次接收的高分辨率单调时间和本地墙上时间；相对时间由采集原点计算，日志时间使用墙上时间
- [x] 波形数据显示区展示 `T+... s`、原始载荷和解析成功状态；不得把主机接收时刻标称为 MCU 采样时刻
- [x] 同一完整原始帧使用既有 RX 日志服务写入，日志 HEX 包含结束符 `0D 0A`
- [x] 波形页停止接收会关闭物理串口、丢弃该连接的待处理输入并解除页面切换锁定；已显示的波形和帧记录保留
- [x] 切换到另一个页面不会自动开始接收，也不会把波形帧加入数据页历史
- [x] QtCharts 来自现有 PySide6，不新增运行时依赖；Qt offscreen 测试覆盖页面初态、互斥、单帧显示、CH1 绘制、日志和停止解锁
- [x] REQ-0001～REQ-0004 的既有数据页打开、收发、显示和日志测试保持通过

## Blocked by

None - can start immediately

## User stories addressed

按父 PRD §2.1 的范围项映射：

- US-1：在“数据”和“波形”页面间切换
- US-2：两页独立开始/停止接收，并隔离各自历史
- US-3：按整数协议接收通道数据（本切片贯通简单单通道帧）
- US-4：查看相对时间、帧状态、波形和通道状态
- US-6：将完整示波器帧写入现有 RX 日志
