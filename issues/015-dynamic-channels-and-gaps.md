# 015 - 动态多通道、短帧缺口与通道栏

## Type

AFK

## Parent PRD

`docs/requirements/REQ-0005-oscilloscope.md`（§7.1、§7.2.1、§7.3、§13.3.1-13.3.2）

## What to build

把完整整数帧端到端映射为动态多通道波形。采集会话按见过的最大合法字段数递增建立 CH1～CH8；每帧所有实际字段共享同一个相对时间。右侧通道栏显示每个已发现通道的名称、开关和最新有效值，关闭通道只隐藏曲线。

合法短帧中缺少的后续字段必须作为明确的数据缺口进入绘图语义，使曲线真正断开；不得沿用旧值或让绘图库跨缺口直连。非法帧、短帧和历史淘汰均不得减少会话已发现的通道数。

## Acceptance criteria

- [x] 第一条合法帧按字段顺序建立对应的 CH1～CH8；后续更宽合法帧只增加缺少的通道
- [x] 通道数等于当前采集会话见过的最大合法字段数，并且从不因短帧、非法帧或历史淘汰而降低
- [x] 同一合法帧的实际字段共享完全相同的相对时间，不为缺失字段生成伪采样值
- [x] 合法短帧使缺失的后续通道在该帧时间形成可绘制为断线的缺口，不复制、插值或沿用上一个值
- [x] 新通道默认显示；每个通道在右侧通道栏同时显示 CH 名称、显示开关和最新有效值
- [x] 关闭某通道只隐藏其曲线，接收、原始采样存储和最新有效值更新继续进行；重新打开可从原始历史恢复绘制
- [x] 所有显示通道共用一条 Y 轴，曲线使用主题中可区分的多色方案，并通过通道名称/开关状态同时表达身份
- [x] 非法完整帧不建立通道、不更新最新值，也不改变既有曲线
- [x] 数据模型和 QtCharts 适配测试证明缺口产生分段 series，前后有效点之间没有跨缺口直线
- [x] Qt offscreen 测试覆盖通道动态增长、开关、最新值、短帧和非法帧；既有单通道闭环仍可演示
