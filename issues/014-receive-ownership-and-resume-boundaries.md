# 014 - 接收所有权、停止恢复与连接边界

## Type

AFK

## Parent PRD

`docs/requirements/REQ-0005-oscilloscope.md`（§4、§6.2、§11、§12.3-12.4、§13.1-13.2）

## What to build

完成数据页与波形页共享一个物理串口时的接收所有权和连接生命周期。任意时刻只有活动页面能消费输入；停止、错误、拔出和关闭均在明确的会话边界使旧 reader、队列及未完成帧失效。波形页停止再开始时保留同一采集历史和单调时间原点，但创建全新的串口读取会话、清除驱动待读输入，并只接收重开后进入链路的新数据。

如果停止期间改变端口或任一串口参数，恢复后须在独立波形数据区插入带当前相对时间的新连接边界，同时保留原历史、通道和时间轴。

## Acceptance criteria

- [ ] 任意时刻最多一个页面持有接收所有权，输入不广播到两个页面，也不存在两个页面轮询同一队列的路径
- [ ] 当前页面开始接收后锁定页面切换；停止关闭串口并解除锁定，切换后的另一页面保持停止且需用户主动开始
- [ ] 页面切换本身不自动打开、停止或清空任何页面；活动采集期间切页请求不能绕过锁定
- [ ] 停止时在线性化的连接边界丢弃当前会话待处理队列、未完成帧和旧 reader 延迟返回的数据
- [ ] 每次重新开始都创建新 reader/连接接收会话，并在读取前调用串口驱动输入缓冲清理；缓冲清理失败走明确的打开/连接错误路径
- [ ] 停止期间设备发送的数据不进入内存队列，重开后不得作为旧数据补收；软件不通过保持打开并暂停消费来实现停止
- [ ] 波形停止再开始保留原始采样、帧历史、通道及原采集时间原点；停止经过的单调时间体现在下一条新帧相对时间中，但期间不生成点
- [ ] 相同设置恢复时不拼接停止前半帧；不同端口或参数恢复时插入包含当前设置及相对时间的连接边界记录
- [ ] 参数或端口改变不清空历史、不重置采集原点；只有显式新建采集执行重置
- [ ] 读取错误、写入错误、热拔插和程序关闭均关闭失效连接、使旧消费者会话失效，并恢复可切页/可重开状态
- [ ] 发送只作用于当前打开的物理串口，不进入数据页历史、波形帧历史或采样缓冲
- [ ] 注入单调时钟、墙上时间和可控 fake serial 的测试覆盖停止间隔、驱动缓冲清理、旧 reader 隔离、参数边界及异常解锁
