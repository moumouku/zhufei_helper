# 018 - X/Y 缩放、平移和原始点悬停检查

## Type

AFK

## Parent PRD

`docs/requirements/REQ-0005-oscilloscope.md`（§8、§8.1、§13.3.5-13.3.7）

## What to build

在同一相对时间/十进制数值坐标系统上完成波形检查交互。用户既能通过可见控件独立缩放 X 或 Y，也能用滚轮及修饰键缩放；左键拖动支持联合或单轴平移。所有操作必须围绕图表坐标执行并夹紧到当前三分钟保留窗口和 int32 数值硬边界。

悬停读值必须查询原始采样而非降采样后的绘图点，只有靠近真实采样时才显示该帧的相对时间及实际存在的通道和值；短帧缺失通道不能生成虚构读数。

## Acceptance criteria

- [x] 页面提供可见的 X 轴缩放和 Y 轴缩放操作，不把鼠标滚轮作为唯一入口
- [x] 默认滚轮只缩放 X 轴，`Ctrl+滚轮` 只缩放 Y 轴，均以指针附近对应图表坐标为中心
- [x] 图表内按住左键默认同时平移 X/Y，`Shift+左键拖动` 只平移 X，`Ctrl+左键拖动` 只平移 Y
- [x] 缩放和平移使用当前轴范围作为共享状态，不建立与图表显示脱节的另一套近似坐标
- [x] X 轴始终限制在当前仍保留的采样时间窗口内；没有足够数据时使用合法默认范围
- [x] Y 轴始终限制在 `-2147483648..2147483647`，且极值、常值和反复缩放后范围非零、非反向
- [x] 手动缩放或平移会退出实时跟随；新数据继续采集但不覆盖用户视口，显式“回到最新”才能恢复跟随
- [x] 悬停邻近判定在屏幕/视口尺度上执行，但返回值来自最近的真实原始采样，而不是降采样或插值点
- [x] 悬停提示显示 `T+... s` 及该帧实际存在的通道和值；缺失通道不显示虚构值
- [x] 指针没有靠近有效原始采样时隐藏读值，不保留容易误解为当前位置数据的旧提示
- [x] Qt offscreen 测试覆盖轴数学、边界夹紧和悬停查询；需要真实 QtCharts 事件的滚轮/拖拽在受支持的 Windows 平台补充原生验收
