# 017 - 视口驱动绘图、自动缩放与实时/历史导航

## Type

AFK

## Parent PRD

`docs/requirements/REQ-0005-oscilloscope.md`（§7.3、§8.5-8.9、§8.1、§12.1、§13.3.4-13.3.5）

## What to build

从三分钟原始采样缓冲按当前 X 视口、图表像素宽度和通道开关状态生成 QtCharts 绘图输入。需要简化时，以时间桶保留局部最小值和最大值；每次视口或尺寸变化都从原始数据重新生成，不能改写原始缓冲。短帧缺口继续表现为断线。

提供相互独立的“自动缩放”和“回到最新”：自动缩放一次性适配保留数据与当前开启通道，回到最新恢复实时跟随。用户查看历史时继续采集；若 180 秒滚动窗口淘汰了当前视口左侧历史，将视口夹紧到仍保留范围并非模态提示。

## Acceptance criteria

- [x] 图表 X 轴使用采集相对秒，所有可见通道共用同一 Y 轴；轴范围和绘图数据源均来自同一原始采样坐标系
- [x] 绘图适配器按当前可见 X 范围、图表像素宽度及通道开关重新生成 series，不把 QtCharts 点作为唯一原始存储
- [x] 需要降采样时，每个时间桶保留按时间有序的局部最小值和最大值，高频尖峰在简化后仍可见
- [x] 降采样和重绘不删除、不合并、不改写原始采样；放大或改变视口后可以恢复对应范围内原始细节
- [x] 短帧数据缺口形成独立曲线段，不跨缺口连接；隐藏通道不进入绘制，但原始数据仍保留
- [x] “自动缩放”将 X 适配当前保留采样范围，并只按当前可见 X 范围内已开启通道的有效原始值计算 Y
- [x] 无数据、常值数据、单点数据及无开启通道时均得到非零、非反向且可见的合法默认范围
- [x] “回到最新”移动时间视口至最新保留数据并恢复实时跟随，不隐式执行自动 Y 缩放
- [x] 用户手动离开最新视图后，新数据继续接收、存储、显示和记录日志，但视口不被强制移回或自动缩放
- [x] 历史淘汰越过当前视口边界时，X 范围夹紧至仍保留窗口并显示非模态“历史正在滚动淘汰”状态
- [x] 可注入的绘图资源失败停止波形接收、保留原始历史并解除页面锁定，不把失败降级为静默删点
- [x] 纯数据测试覆盖 min/max 降采样、缺口和原始缓冲不变性；Qt offscreen 测试覆盖自动缩放、回到最新及历史视口
