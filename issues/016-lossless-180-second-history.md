# 016 - 三分钟无损采样与完整帧历史

## Type

AFK

## Parent PRD

`docs/requirements/REQ-0005-oscilloscope.md`（§6.3、§7.1.3、§7.2、§8.7-8.9、§12.1、§13.3.1-13.3.3）

## What to build

为波形页提供两个相互一致但推进基准各自明确的三分钟窗口：合法采样使用最新合法采样的相对时间推进，数据显示区使用最新完整帧的相对时间推进。采样存储必须紧凑保存窗口内全部实际原始十进制数值，不以固定点数截断或以绘图对象代替；数据显示区保留合法和非法完整帧。停止期间没有新输入时，两种历史都不能仅因电脑时间流逝而淘汰。

数据区默认跟随最新，用户查看旧记录时继续接收但保持阅读位置，并提供返回最新。若内存分配或继续保留数据已无法安全进行，停止波形接收、保留已有历史并显示非模态错误。

## Acceptance criteria

- [x] 每条合法帧只保存该帧实际存在字段的原始十进制数值及共同相对时间，使用独立于 QtCharts 绘图对象的紧凑存储
- [x] 原始采样保留最新合法采样时间向前 180 秒内的全部值；无固定点数上限、无采样率降采样删除
- [x] 采样淘汰严格以最新合法采样时间推进；非法帧不能单独推进采样窗口
- [x] 波形数据显示区保留最新完整帧时间向前 180 秒内的全部合法和非法帧记录
- [x] 数据区淘汰以最新完整帧相对时间推进；合法采样窗口和完整帧窗口不得误用同一个不匹配的推进锚点
- [x] 停止接收后即使注入时钟继续前进，已有采样和帧记录也保持不变；恢复后分别随新合法采样或新完整帧推进窗口
- [x] 旧样本或帧记录淘汰不降低已发现通道数，也不改变仍保留原始点的值和时间
- [x] 数据区默认跟随最新；用户查看旧记录后新帧继续进入历史和日志但不强制移动阅读位置，点击“回到最新”恢复跟随
- [x] 原始存储可供后续按任意视口重新构造绘图输入，当前绘图简化不得反向修改它
- [x] 可注入的内存/存储失败会停止波形接收、关闭串口、解除页面锁定、保留此前数据并显示非模态错误，不静默删除窗口内数据
- [x] 测试使用高采样率和边界时间证明 180 秒内点数全量保留、边界外数据准确淘汰，并证明停止期间不淘汰
